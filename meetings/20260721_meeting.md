# Meeting: Initial discussion with ABC and Hengen Lab — implementation plan

- **Date:** 2026-07-21
- **Time / duration:**
- **Attendees:** Matt Gaidica (NTH), Jemin (NTH), ABC team, Ravi Chopra (HLAB)
- **Phase:** Phase 2 — NTH Engineering Sprint

## Agenda

1. Implementation plan with ABC and Hengen Lab
2. Node-module upgrades: pellet presence sensing
3. Experiment tasks and alpha software path
4. Home-cage requirements and IACUC implications

## Discussion

- First joint implementation discussion with ABC and Hengen Lab.
- Matt introduced the hardware; Jemin introduced the alpha software.
- Agreed the node module needs an upgrade to **pellet presence sensing**, not
  dispense-only, so experiment tasks can reason about whether a pellet is
  actually in the well.
- Covered experiment-task needs for both labs (common ABC tasks and HLAB
  custom experiments) and a week-8 rollout target as then planned.
- **Project status at the meeting:** awaiting beam-break sensor PCBs (then
  expected July 28) and finalizing 3D design. Alpha software had exposed
  events and demonstrated connectivity. NTH was preparing a build week and
  beta hardware/software distribution.

## Decisions

- Upgrade the node module for pellet presence sensing (priority over later
  detector work).
- Treat experiment-task support as part of the same implementation plan, not
  a follow-on after hardware freeze.
- Add bedding offset so “home cage” intent is met.
- Pursue IACUC protocol amendment.
