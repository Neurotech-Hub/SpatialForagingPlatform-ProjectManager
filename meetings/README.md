# Meeting Notes

Lightweight record of cross-lab meetings and major site events. The intent is
to capture decisions and action items so the rest of the team can stay aligned
without attending every call. Full transcripts are not required.

Weekly shipped / blocked / next updates live in [`pulse/`](../pulse/), not
here.

## How to add a note

1. Copy [`TEMPLATE.md`](TEMPLATE.md) to a new file named
   `YYYYMMDD_meeting.md`.
   Example: `20260721_meeting.md`.
2. Fill in attendees, agenda, decisions, and action items.
3. Add the note to the index below.
