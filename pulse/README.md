# Weekly pulse

Short, dated progress notes — what shipped, what is in flight, and what is
blocked. One entry per **project week**. Week 0 starts 2026-06-08 (Monday).
Weeks run Monday–Sunday.

Meeting decisions belong in [`meetings/`](../meetings/). This log is the
status heartbeat so anyone can see progress without reading every commit.

## How to update

1. Each Monday, copy [`TEMPLATE.md`](TEMPLATE.md) to the **top** of
   [`log.md`](log.md) (newest week first).
2. Fill shipped / in progress / blocked / next. Bullets, not prose.
3. If a cross-lab meeting or site event happened, link the meeting note.
4. When the week number or phase changes, update the **Current status**
   tables in [`PROJECT.md`](../PROJECT.md) and [`README.md`](../README.md).
